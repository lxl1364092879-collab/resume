03 — 库存看板搭建

技术架构 · 构建层（本地 Node）：build-inv.js 解析 stock.xlsx + stock_big.xlsx + info.xlsx 生成 D.inv（各维度库存聚合）与 D.age（SKU 明细/周转/分仓）；build-sup.js 解析当期/同期指标表生成 D.sup（含同比）；build-meta.js 解析保密商品明细 CSV 生成 D.skuMeta（SKU 主图+商详链接）。服务层 server.js 读缓存，经 /api/data（gzip）一次性下发，兼容旧缓存缺 skuMeta 的自动补齐。前端 index.html 1839 行单文件，无框架无构建，视角切换/排序/搜索/下钻全在前端完成。

功能全景 · 部门视角：核心指标 → 维度明细（部门/品牌-品类/C3×品牌/采销员，可搜索排序）→ TOP100 销售额商品周转 → 不健康库存 → 缺货表现。采销视角：核心指标 → 品牌→供应商→类目三级下钻 → SKU 周转明细（含 PV 现货率）→ 按该采销员重算的 TOP100 → 不健康/缺货（自动过滤到人）。

交互能力：所有表格列排序、搜索过滤、SKU 商品图+品名+编码合并展示（点图放大、点名跳商详）、不健康库存分仓展开、不健康/缺货/SKU 周转 CSV 导出（可按部门/采销员筛选）、周转颜色预警（<10 天红、10-40 绿、40-60 黄、>60 红）。
